Miss Poppy Rabbit

A fully-local pocket assistant OS for the M5Stack Cardputer — 117% local

INSTALL FROM YOUR BROWSER

Flashes the complete firmware (apps + Web UI) over USB using WebSerial. Works in Chrome or Edge on desktop. Both the original Cardputer and the Cardputer ADV are supported.

  1. Plug your Cardputer in with a USB-C data cable
  2. Click Install and pick the serial port (usually usbmodem / COM)
  3. Wait ~1 minute. The rabbit will greet you 🐰

If the port doesn't show up: hold the G0/BOOT key while plugging the cable, then try again. Choosing "Erase device" is recommended for first installs.

AFTER FLASHING

  1. Open Settings on the device, scan and join your WiFi
  2. Insert any FAT32 microSD card (your tasks & events live there)
  3. Visit http://prabbit.local from a browser on the same network for the Web UI
  4. Optional: install the Chrome extension to auto-sync Google Calendar / Outlook
